# Screenshots Directory

Store your application screenshots or GIFs in this directory with the following filenames to automatically display in the root `README.md`:

1. `home.png` — Landing page / welcome hero banner and navigation.
2. `create_account.png` — User account registration form and validation status.
3. `login.png` — User authentication modal/form.
4. `deposit.png` — Deposit interface showing balance update and success alert.
5. `withdraw.png` — Withdrawal interface demonstrating overdraft protection.
6. `alldata.png` — All Data ledger showing persistent user profiles and balances.
